# 🛡️ Hardened Polyglot Sandbox (HPS)

A cloud-agnostic, zero-cost security evaluation environment designed to run untrusted LLM-generated code safely inside a restricted container sandbox. This system uses unprivileged user containment, custom system call routing policies, and automated risk scoring engines to neutralize host vulnerabilities.

## 🚀 Architectural Design & Features
* **Zero-Trust Privilege Context**: Forcefully maps execution scopes to an unprivileged non-root context (`UID 65534 / nobody`).
* **Seccomp Layer Interception**: Utilizes system-level whitelisting policies to deny unauthorized operational execution loops.
* **Automated Telemetry Platform**: Built using a Python automation daemon and an interactive Flask web console providing live security postures.

## 📁 Project Workspace Layout
* `seccomp-profile.json` — Custom kernel restriction policy dictionary.
* `sandbox_engine.py` — Core automation script that boots sandboxes and gauges compliance scores.
* `app.py` — Web interface delivering real-time logs and graphic telemetry indicators.
* `untrusted_code/` — Target directory holding compiled binaries generated by the model.

## 🛠️ Step-by-Step Installation & Execution

### 1. Build and Compile the Execution Target
Run this inside your terminal workspace to generate the unprivileged testing binary:
```bash
docker run --rm -v $(pwd)/untrusted_code:/src -w /src alpine sh -c "apk add --no-cache build-base && gcc malicious_test.c -o test_binary"
```

### 2. Launch the Automated Engine (Terminal Mode)
To view raw risk evaluation profiles right in your console shell:
```bash
python3 sandbox_engine.py
```

### 3. Initialize the Web Dashboard Interface
To deploy the live telemetry site interface:
```bash
pip install flask
python3 app.py
```
*Navigate to port `5000` via your secure browser forwarding loop to view compliance metrics.*
